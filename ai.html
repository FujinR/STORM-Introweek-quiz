Five quick questions on how learning systems actually work under the hood. Cheat sheet included for anything new.

Cheat sheet

  • Supervised learning: the model learns from examples that already have the correct answer attached (labeled data).
  • Unsupervised learning: the model finds structure in data with no correct answers given.
  • Overfitting: when a model memorizes the training examples instead of learning the general pattern, so it performs badly on new data.
  • Training data: the examples a model learns from. Test data: new examples used to check how well it actually learned.
  • Weight: a number the model adjusts during training to control how much influence an input has on its output.

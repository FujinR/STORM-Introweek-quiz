Cheat sheet

  • Variable: a named box that stores a value, e.g. x = 5.
  • Loop: repeats a block of instructions until a condition is met.
  • Big-O notation: a rough measure of how an algorithm's running time grows as input size grows. O(1) is constant, O(n) is linear, O(n²) is quadratic.
  • Binary search: repeatedly halves a sorted list to find a target — much faster than checking every item.
  • Boolean: a value that's either true or false.

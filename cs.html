Cheat sheet

  • range(a, b): counts from a up to (but not including) b.
  • Big-O notation: how running time grows with input size. O(1) constant, O(log n) logarithmic, O(n) linear, O(n²) quadratic.
  • Binary search: halves a sorted list each step. Number of steps needed ≈ log₂(size).
  • De Morgan's Law: NOT (A AND B) is the same as (NOT A) OR (NOT B).
  • Truth table: a table listing every input combination and the resulting output for a logical expression.

The Sequence Gate

Theo found an old stone gate covered in numbers and symbols. Legend says it only opens for someone who can actually read them.

Cheat sheet

  • Arithmetic sequence: each term adds a fixed amount to the last. nth term = first term + (n−1) × step.
  • AND / OR: "P AND Q" is true only if both are true. "P OR Q" is true if at least one is true.
  • Subsets: a set with n elements has 2ⁿ possible subsets (including the empty set and the full set).
  • Proof by induction: (1) show it's true for the smallest case, (2) assume it's true for some n, then show it must also be true for n+1.
  • Sum of 1 to n: n × (n+1) ÷ 2.
